# Проверка базовых пользовательских требований

`testcases.py` выполняет 14 тест-кейсов уровня базовых пользовательских
требований на работающем экземпляре программного средства и сравнивает
фактический результат каждого шага с ожидаемым.

```bash
java -jar ../target/kalplat-api-1.0.0.jar &      # запуск программного средства
python3 testcases.py                              # выполнение тест-кейсов
```

Результаты сохраняются в `testcases.json`: идентификатор тест-кейса,
проверяемое требование, шаги, ожидаемый и фактический результаты,
длительность выполнения.
